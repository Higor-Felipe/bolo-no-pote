# Bolo no Pote - Encomendas
## Projeto de encomendas de bolo no pote na EXPOTEC da ETEC Renato Cordeiro - turma: 2º Marketing

### Objetivo:
O objetivo principal é fornecer uma ferramenta funcional para gerenciar encomendas de bolos no pote pelo whatsapp de forma simples, compacta e gratuíta com uma interface simples e de fácil utilização.

## Link: https://higor-felipe.github.io/bolo-no-pote/

### Funcionalidades:
  - **Encomendar bolo:**
      Adcionar encomendas de bolo ao carrinho.
  - **Inserir quaditade de bolo:**
      Ao clicar em adicionar no determinado sabor, selecione a quantidade desejada para a encomenda.
  - **Carrinho de Compras:**
      Clique no ícone de carrinho para acessar o carrinho de compras para finalizar o pagamento colocando o nome e método de pagamento.
  - **Método de pagamento:**
      Selecione o método de pagamento, se escolhido o pix, aparece o Qr Code para escanear e a chave pix com um botão de copiar.
  - **Envio ao Whatsapp:**
      Logo após o preenchimento dos dados, clique no botão de enviar a emcomenda para o Whatsapp para uma melhor gestão de pedidos.
  - **Local Storage:**
      Caso o cliente feche o site após ter adicionado um pedido no carrinho de compras, o pedido é salvo no Local Storage para não houver a perca desse pedido.

### Tecnologias Utilizadas:
  - **HTML5**: Estrutura da página.
  - **CSS3**: Estilização do layout, com Flexbox para organização e media queries para responsividade.
  - **JavaScript**: Lógica para adicionar o pedido no carrinho, método de pagamentos, envio ao whatsapp e integração com LocalStorage.
  - **LocalStorage**: Armazenamento local para persistência de dados.
  - **Bootstrap**: Uso para uma melhor manutenção da lógica, no layout dos produtos, nav bar e formulários.

### Uso
  - **Adcionar pedido**:
Escolha um sabor dentre os disponíveis e clique em adicionar.
Adicione a quantidade desejada de bolos e clicar em "Adicionar".
O pedido será adicionado ao carrinho de compras.

  - **Carrinho de compras**:
Clique no ícode de carrinho de compras para acessar ao carrinho.
Preencha o formulário com as informações necessárias (nome e método de pagamento).
No método de pagamento, siga as instruções para efetuar o pagamento.

  - **Envio ao Whatsapp**:
Quando finalizar o formulário, clique em "Enviar Pedido ao Whatsapp" para concluir a encomenda.

  - **Excluir um pedido**:
Para excluir o pedido, será necessário clicar no botão de lixeira no carrinho de compras para excluir o sabor adicionado anteriormente.

  - **Persistência**:
Os pedidos não concluidos são salvos no Local Storage do navegado para não ter perda de dados.
Ao recarregar, ou sair da página, os pedidos não concluídos continuarão salvos.
